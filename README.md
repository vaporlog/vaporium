# Vaporium - The Vaporization Encyclopedia

[![Live Site](https://img.shields.io/badge/Live-Site-4caf50?style=for-the-badge&logo=github)](https://vaporlog.github.io/vaporium/)

Welcome to **Vaporium**, the definitive community encyclopedia for dry herb vaporization. This is a methodical, open-source archive dedicated to documenting strain profiles, session logs, and technical vaporization guides.

## 🚀 Quick Access
**View the live encyclopedia here:** [https://vaporlog.github.io/vaporium/](https://vaporlog.github.io/vaporium/)

## 🌿 Project Mission
Vaporium moves beyond commercial interests to build a systematic database. Our goal is to help enthusiasts find their "sweet spot" by sharing precise data on:
- **Strains:** Chemical profiles, terpenes, and lineages.
- **Sessions:** Vaporizer settings, temperatures, and sensory results.
- **Experience:** Moods, activities, and ratings.

## ✨ Key Features
- **Advanced Filtering:** Search sessions by device, mood, or temperature ranges.
- **Interactive UI:** Modern cards with visual potency meters and color-coded tags.
- **Community Comments:** Discussions powered by GitHub Issues (via Utterances).
- **Fully Responsive:** Optimized for desktop and mobile devices.
- **Dark Mode:** Support for automatic and manual theme switching.

## 🤝 How to Collaborate
Vaporium is built by the community. You can contribute in two ways:

### 1. GitHub Pull Request (Recommended)
- Fork this repository.
- Add your `.md` files to `content/strains/` or `content/sessions/`.
- Submit a Pull Request for review.

### 2. Email Submission
- Copy the YML templates found on the Collaborate page.
- Fill in your data and send it to: **unalumnodel02@gmail.com**.
